1

Start Python Backend

Launch the WebSocket server on your laptop. It runs YOLOv11s detection and the reactive planner.

# First time only cd prototype/backend ./setup.sh # Then start server uv run python server.py
  • Terminal shows
    WebSocket server started on ws://0.0.0.0:8080
  • Model loaded
    Loaded YOLO model from yolo11s.pt on device 0
2

Get Laptop IP Address

Find your laptop's LAN IP so the Android app can connect. Both devices must be on the same WiFi.

ip route get 1.1.1.1 | awk '{print $7}'

Example output: 192.168.0.105

Enter the IP above to pre-fill the connection command in Step 3.

3

Connect Android App

Build and run the app, then enter the backend address.

  1. Open prototype/frontend/Android App in Android Studio
  2. Build & run on device (USB or wireless ADB)
  3. Grant Camera Permission when prompted
  4. Enter address: 192.168.x.x:8080
  5. Tap Connect
192.168.x.x:8080

Troubleshooting
"Connection refused"

Start backend first, then connect Android. Check firewall: ufw allow 8080

"Unknown host" / Timeout

Both devices on same WiFi? Verify IP with ip route get 1.1.1.1 | awk '{print $7}'

Low FPS / Late boxes

CameraProvider now uses 1280×720 @ Q85 + AE/AF lock. Restart app after rebuild.

CUDA OOM

Edit perception.py:14 → device="cpu" or use yolo11n.pt
